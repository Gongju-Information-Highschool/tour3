# static/leaflet/ — 지도 라이브러리를 넣는 자리

이 폴더는 **비어 있습니다.** 그래도 서비스는 완전히 동작합니다 —
`app.py`가 번들이 없는 것을 알아채고 자동으로 **좌표로 그린 위치 관계 그림(SVG)**
으로 화면을 바꿉니다(기획안 §6.4). 점수·필터·찜·동선 전부 그대로 작동합니다.

진짜 지도 타일 위에 마커를 찍고 싶으면 아래 세 파일을 여기에 넣으세요.

```
static/leaflet/
├── leaflet.js
├── leaflet.css
└── images/          (마커 아이콘. leaflet.css가 참조합니다)
```

## 받는 방법

Leaflet 공식 배포본(https://leafletjs.com/download.html)에서 `leaflet-1.9.4.zip`을
내려받아 압축을 풀고, 그 안의 `leaflet.js` · `leaflet.css` · `images/` 를
이 폴더에 그대로 복사합니다.

## 왜 CDN을 쓰지 않나

학교망은 CDN을 막는 경우가 많습니다. 수업 당일 지도가 안 뜨는 것을 막으려고
파일을 폴더 안에 두는 방식(로컬 번들)을 택했습니다.
같은 이유로, 번들이 없거나 타일 서버에 닿지 않으면 자동으로 SVG로 넘어갑니다.

## 확인

넣고 나서 서버를 다시 켜면 시작할 때 이렇게 찍힙니다.

```
지도 방식 : leaflet   (leaflet 번들 있음 / 타일서버 연결됨)
```

`svg`라고 나오면 파일 이름이나 위치가 다른 것입니다.
